The images below illustrate a historical interface run and do not validate this source revision. Starting the tour creates your own run; it does not replay a saved result.

Step 1 of 6

Open the example

Choose Nonce exchange and select Open example. VAKE saves a separate copy for this run.

You can inspect the roles before running any checks.

Step 2 of 6

Check the model

Select Check model. The parser and type checker must accept the supported input before you continue.

An invalid model shows its diagnostic here.

Step 3 of 6

Create Lean files

Select Create Lean files. VAKE translates the model using the saved profile.

Files have been created; no proof has been checked yet.

Step 4 of 6

Run Lean

Select Run Lean checks. VAKE independently imports the source and checks its bindings to the generated target.

A successful result is checked under the selected assumptions. It does not establish authentication or secrecy.

Step 5 of 6

Inspect the execution

Select Check execution traces. Compare the honest exchange with the malformed-message rejection.

The bundled example has 15 honest actions and six rejection actions. Expand a scenario to inspect its checked steps.

Step 6 of 6

Save the evidence

Select Download evidence ZIP. Keep the model, Lean files, commands, outputs, and hash manifest together.

Logs, proof inventories, and reproduction commands are available when you need them.

What this walkthrough demonstrates

Model checking, source/target binding checks, named Lean certificates, and two concrete execution scenarios. Authentication, secrecy, replay resistance, and general attacker analysis remain open or unsupported. The source documentation records the detailed assumptions and validation coverage.
